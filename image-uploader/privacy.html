隱私權政策

適用對象：桌面工具「圖片上傳器」　·　生效日：2026-09-05

1. 這個應用程式是什麼

「圖片上傳器」是一支在本機電腦執行的 Python 命令列工具，用途是把作者整理好的圖片檔 上傳到作者本人的 Google 雲端硬碟資料夾，並產生一份含下載連結的試算表清單。

本工具不是公開服務：沒有網站、沒有伺服器、沒有註冊或登入功能， 也不提供給其他人使用。它只在執行者自己的電腦上跑，唯一會被存取的 Google 帳號， 就是在授權畫面上登入的那個帳號本人。

2. 我們蒐集哪些資料

不蒐集任何資料。

本工具沒有後端伺服器，也沒有資料庫。它不會把任何個人資料、檔案內容、 使用行為或裝置資訊傳送給作者或任何第三方。作者無法看見、也無從取得 任何使用者的資料。

本工具不使用 Cookie、不內嵌分析工具、不投放廣告、不做跨站追蹤。

3. Google 使用者資料的存取範圍

本工具透過 Google Drive API 運作，授權時會要求以下權限範圍（scope）：

  • https://www.googleapis.com/auth/drive

用途

這個權限僅用於下列動作，全部針對執行者自己帳號中的雲端硬碟：

  • 把本機圖片檔上傳到執行者在設定檔中指定的雲端硬碟資料夾。
  • 把上傳完成的檔案共用權限設為「知道連結的人皆可檢視」，以便產生可分享的下載連結。
  • 讀取指定資料夾中既有的檔案名稱，用來判斷某張圖是否已經上傳過，避免重複上傳。

不會做的事

  • 不會存取上述指定資料夾以外的檔案。
  • 不會刪除使用者的雲端硬碟檔案。
  • 不會下載、複製或保留檔案內容到本機以外的任何地方。
  • 不會把 Google 使用者資料用於訓練任何 AI／機器學習模型。
  • 不會把 Google 使用者資料轉移、販售或分享給任何第三方。

本工具對 Google 使用者資料的使用，遵守 Google API 服務使用者資料政策， 包含其中的「有限使用」（Limited Use）規定。

4. 憑證存放在哪裡

授權完成後，Google 發出的存取憑證（access token 與 refresh token）只會被寫入 執行工具那台電腦上的檔案 .token.json，位於工具自己的資料夾內。

  • 憑證不會被傳送到任何伺服器，作者也無法取得。
  • 憑證不會被納入原始碼版本控制。
  • 憑證只有這台電腦上的使用者本人能存取。

5. 資料保留與刪除

由於本工具不蒐集資料，也就沒有需要保留或刪除的資料。使用者可以隨時終止本工具的存取權：

  • 到 Google 帳號 → 第三方應用程式與服務 找到本應用程式，選擇「移除存取權」；以及／或者
  • 直接刪除本機工具資料夾中的 .token.json 檔案。

撤銷之後，本工具即無法再存取該帳號的雲端硬碟，直到重新授權為止。

6. 兒童隱私

本工具為作者個人開發用途，並非針對兒童設計，也不會向任何人蒐集資料。

7. 政策變更

本政策若有更新，會直接修改本頁內容並更新頁首的生效日期。

8. 聯絡方式

English summary

Image Uploader is a personal, locally-run command-line tool. It collects no data whatsoever: it has no server, no database, and no analytics, and it transmits nothing to its author or to any third party. It requests the Google Drive scope https://www.googleapis.com/auth/drive solely to upload image files to folders the operator specifies in their own Google Drive, to set those files' sharing permissions so download links can be generated, and to read existing file names in those folders in order to skip duplicate uploads. It never deletes files, never accesses files outside those folders, never uses Google user data to train AI or machine-learning models, and never transfers Google user data to third parties. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. OAuth tokens are stored only in a local .token.json file on the operator's own machine and are never uploaded anywhere. Access can be revoked at any time via Google Account permissions or by deleting that local file. Questions: lionjpworldadad@gmail.com.
